# Security policy

## Supported releases

Security fixes, when available, target the latest published release. Older releases are not maintained. This early-stage project does not promise a response or fix within a particular time.

## Report a vulnerability privately

Use GitHub's **Report a vulnerability** button on the [agree-first security advisories page](https://github.com/felipecepluki/agree-first/security/advisories). Private vulnerability reporting is enabled for this repository, so the report is shared with maintainers rather than published as an issue.

Please include the affected version, steps to reproduce, expected and actual behavior, and potential impact. Do not put vulnerability details or proof-of-concept code in a public issue, discussion, or pull request. If the private form is unavailable, open a public issue asking for a private contact method **without including any vulnerability details**.

Maintainers will review reports privately and coordinate any fix and disclosure with the reporter. The package is a UI library, not a legal compliance service; questions about a product's legal obligations are outside this security reporting process.
